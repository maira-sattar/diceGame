
# Dice Game

A simple, interactive browser-based dice game built using HTML, CSS, and JavaScript.

## Built With
* **HTML** - Structure and markup
* **CSS3** - Styling, layout, and responsiveness
* **JavaScript** - Game logic, interactivity, and score handling

## Features
* **Interactive Gameplay:** Roll the dice, manage your turn scores, and test your luck right in your browser.
* **Dynamic Dice Rendering:** Real-time image updates corresponding to every dice roll.
* **Responsive Design:** Clean, modern UI styled with custom CSS.
