# Dice Game

A simple, interactive browser-based dice game built using HTML, CSS, and JavaScript.

## Built With
- **HTML** (Structure)
- **CSS** (Styling & Layout)
- **JavaScript** (Game Logic & Interactivity)

## Features
- **Interactive Gameplay:** Roll the dice and test your luck right in your browser.
- **Responsive Design:** Clean styling built with custom CSS.
